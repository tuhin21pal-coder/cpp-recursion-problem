# Recursion Problems in C++
This folder contains a collection of C++ programs focused on Recursion. These problems are designed to strengthen problem-solving skills and develop a better understanding of recursive functions, base cases, and recursive calls.

# Programs Included
| No. | Program | Description |
|---|---|---|
| 1 | Array Sum | Calculates the sum of array elements using recursion. |
| 2 | Array Reversal | Reverses an array using recursive calls. |
| 3 | Binary Search | Searches for an element in a sorted array recursively. |
| 4 | Decimal to Binary | Converts a decimal number into binary using recursion. |
| 5 | Fibonacci Series | Calculates Fibonacci numbers using recursion. |
| 6 | GCD | Finds the Greatest Common Divisor of two numbers recursively. |
| 7 | Largest Element in Array | Finds the largest element in an array using recursion. |
| 8 | Logarithmic Power | Calculates the power of a number using an optimized recursive approach. |
| 9 | Multiplication | Performs multiplication using recursive addition. |
| 10 | Number of Digits | Counts the number of digits in an integer using recursion. |
| 11 | Palindrome Checker | Checks whether a number is a palindrome using recursion. |
| 12 | Power | Calculates the power of a number using recursion. |
| 13 | Reverse Number | Reverses a number using recursion. |
| 14 | Sorted Array Checker | Checks whether an array is sorted using recursion. |
| 15 | Stair Steps (2 stairs maximum) | Solves the stair-step problem using recursion. |
| 16 | Stair Steps (3 stairs maximum) | Explores another recursive approach to the stair-step problem. |
| 17 | Sum of Digits | Calculates the sum of digits of a number using recursion. |
